Overview

Accurate, automated identification and susceptibility testing system featuring comprehensive ID/AST panels, and an intelligent, streamlined workflow for maximum efficiency.

The system provides comprehensive morphology and culture analysis, along with pathogenicity and epidemiological data for common strains, helping laboratories verify the accuracy of identification results. It flags rare antimicrobial resistance, conflicting susceptibility results, and other phenotype- and treatment-related information based on CLSI/EUCAST standards and multiple clinical guidelines.

Moreover, the system supports identification of more than 200 antimicrobials and can accommodate up to 32 specimens for simultaneous testing, with real-time inspection capability. During the test card detection process, features such as automatic dynamic interpretation, data collection, and self-inspection greatly optimize workflow efficiency.

Data files in WHONET-approved format can be exported with a single click, eliminating the need for additional software conversion. The software also offers multi-dimensional statistical analysis, including bacterial detection rates, antibiotic resistance rates, resistance trends, multidrug resistance phenotypes, submission rates, workload, and more.
